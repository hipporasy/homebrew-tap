# hipporasy/tap

Homebrew formulae for [hipporasy](https://github.com/hipporasy)'s tools.

```bash
brew install hipporasy/tap/devicehub-ax
```

| Formula | What it is |
|---|---|
| `devicehub-ax` | [ax](https://github.com/hipporasy/devicehub-ax): fold, rotate and tap the iPhone Duo simulator from the command line |

The `devicehub-ax` formula is updated by that repo's release workflow.
